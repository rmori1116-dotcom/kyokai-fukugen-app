# 境界復元支援アプリ（地理院地図版）

SIMA / CSVから境界点を取り込み、現地での打設・既設の記録、計測線、手書きメモ、オフライン利用を支援するPWAです。

## v0.3

- IndexedDBを `kyokaiFukugenMap` へ分離し、選点地図版との端末内データ衝突を解消
- localStorageとオフラインキャッシュも境界復元専用名へ統一
- 選点版由来の杭種オブジェクトを検出し、文字列の初期値へ自動修復
- 初期杭種を「コンクリート杭／プラスチック杭／金属鋲／金属標／金属プレート」の5種類に変更

## v0.2

- 復元・計測時の点選択を、タッチ端末では半径44pxまで拡大
- 指ぶれを14pxまで許容し、タップがドラッグ扱いになりにくいよう改善
- ボタン、入力欄、タブ、一覧、ダイアログを44〜52px以上のタップ領域に統一
- スマホ縦画面・横画面、セーフエリア、スクロール表示を調整
- GitHub Pagesによる自動公開に対応

## 配信ファイル

公開用ファイルは `dist/` にあります。`main` ブランチへpushすると、GitHub ActionsがGitHub Pagesへ自動配信します。

## ビルドとテスト

```sh
python prep.py
python build.py
node test.mjs
```

詳細は `ソース一式_README.md` を参照してください。
