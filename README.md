# 境界復元支援アプリ（地理院地図版）

SIMA / CSVから境界点を取り込み、現地での打設・既設の記録、計測線、手書きメモ、オフライン利用を支援するPWAです。

## v0.10

- **レイヤ画面から色を直接変えられる**ように。画地の線・地番名・計測線・距離・基準点と、打設・既設・未の各行に色のボタンを追加（「表示設定」まで行かなくてよい。中身は同じ設定）
- **取り込んだファイルごとの色**を追加。［レイヤ］→「取り込んだファイル」で1件ずつ色を決められる。隣り合う地区の画地を2つ取り込んだときに、どちらの線かが色で分かる
- ファイルごとの色が効くのは**画地の線と地番名だけ**。境界点は打設（赤）・既設（青）・未（灰）のまま（どこまで打ったかが色で分かることを優先）
- 色を付けたファイルには［このファイルの色を「表示設定」に戻す］が出る。既定は全ファイルとも従来どおりの色
- 色は現場ごとに保存（`imp.color`。取込ファイルの記録に持たせるため、現場の控えにも入る）

## v0.9

- 地番（画地名）を**画地線で囲まれた中（内側）**へ置くよう修正。v0.6〜v0.8は拡大したとき「見えている画地線の長さの真ん中」＝**線の上**に出ていた
- 内側の探し方は、横線を21本引いて画地線との交点を数える偶奇判定。**画面に見えている内側**だけを見るので、拡大しても地番が画面の外へ出ない
- 横書きなので、内側の**横に広く空いているところ**を選ぶ（細長い画地では上下の真ん中から少しずれる）
- 名前が重なるときは、内側の別の空いているところへずらす。線が閉じていない画地だけは、これまでどおり線の上に出す

## v0.8

- 画面の案内と説明の「粒だけ表示」を**「点だけ表示」**へ変更（測量の現場で使わない言い方だったため）

## v0.7

- **現場（プロジェクト）別保存**。端末に現場を並べて持ち、開けるのは1つ。初期5件・設定で1〜10件
- 現場の一覧（作る／開く／名前を変える／削除）をヘッダーの現場名と「準備」タブの［現場］から
- 現場ごと: 点・画地・記録・計測線・メモ・レイヤ・座標系・表示設定・自動控え／端末共通: 作業者名・杭種・文字サイズ・間引き・背景地図・地図の控え
- v0.6までのデータは初回起動で「現場１」へ自動移行（旧キーは残す。古い自動控えも現場に結び付ける）
- 控えの保存はいまの現場だけ（ファイル名に現場名）。読み込みは「合流」か「新しい現場として読む」を選択。別の現場の控えは警告
- ［全データ削除］を［この現場を空に］と［全現場を消す］の2つに分割
- 地番名を**取込ファイルごと**に表示／非表示（レイヤ画面に「地番名」の節。全体スイッチも残す）
- **IDの衝突を修正**。流用元の `uid()` は数千件を一度に作ると同じミリ秒で重なることがあり、画地の辺や記録が別の点に付く恐れがあった。通し番号を混ぜた `newId()` に変更

## v0.6

- 画地名（地番）を画地ごとに1つ地図へ表示（SIMA D00の区画名。レイヤで表示／非表示）
- 画地が丸ごと見えているときは画地の真ん中、拡大してはみ出しているときは画面に見えている画地線の長さの真ん中へ配置
- 名前が重なるときは、その画地自身の線に沿ってずらして配置
- 画地名の色・大きさを「線の表示」設定に追加
- CSVダウンロードのテストを、ヘッドレスChromiumでも保存名を確認できる形へ修正

## v0.5

- 「金属プレート」を「アルミプレート」へ変更（略称 `L`）
- 「マーキング」を「ペンキ」へ変更し、略称を半角 `M` へ変更
- 境界点を取込ファイル順・SIMA内の点順で並べる10列CSV出力を追加
- CSVは元の点名、X/Y/Z、固定マーク `12,1.0,1,1`、杭種、空欄の点種・リンク、既設点の備考をShift-JISで出力

## v0.4

- 復元点の表示名に杭種略称を追加（例: `A1P`）。保存済みの点名そのものは変更しない
- 略称はプラスチック杭 `P`、金属鋲 `B`、金属標 `K`、金属プレート `L`、マーキング `Ｍ`、コンクリート杭 `C`
- 初期杭種へ「マーキング」を追加し、v0.3の杭種設定も利用者の追加項目を保ったまま移行

## v0.3

- IndexedDBを `kyokaiFukugenMap` へ分離し、選点地図版との端末内データ衝突を解消
- localStorageとオフラインキャッシュも境界復元専用名へ統一
- 選点版由来の杭種オブジェクトを検出し、文字列の初期値へ自動修復
- 初期杭種を「コンクリート杭／プラスチック杭／金属鋲／金属標／金属プレート」の5種類に変更

## v0.2

- 復元・計測時の点選択を、タッチ端末では半径44pxまで拡大
- 指ぶれを14pxまで許容し、タップがドラッグ扱いになりにくいよう改善
- ボタン、入力欄、タブ、一覧、ダイアログを44〜52px以上のタップ領域に統一
- スマホ縦画面・横画面、セーフエリア、スクロール表示を調整
- GitHub Pagesによる自動公開に対応

## 配信ファイル

公開用ファイルは `dist/` にあります。`main` ブランチへpushすると、GitHub ActionsがGitHub Pagesへ自動配信します。

## ビルドとテスト

```sh
python prep.py
python build.py
node test.mjs
```
